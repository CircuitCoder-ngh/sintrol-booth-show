Offline videos

The show links to Sintrol videos on YouTube. To play one without internet, save the MP4 here
(for example from the Sintrol partner mediabank) and set its file in assets/js/data.js, e.g.

  { id: "fuWeiSRVqG4", title: "S305QAL dust monitor", group: "Products", product: "s305qal", file: "assets/video/s305qal.mp4" },
